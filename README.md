# GuitarHub

Веб-платформа для обучения игре на гитаре с использованием клиент-серверной архитектуры.

## Описание проекта

GuitarHub — это веб-приложение, предназначенное для поддержки обучения игре на гитаре.  
Платформа предоставляет пользователям доступ к обучающим материалам, аккордам, табулатуре и персональному прогрессу обучения.

Проект разрабатывается в рамках учебной дисциплины по программной инженерии.

---

## Архитектура

Проект реализуется по клиент-серверной модели.
- **Frontend** — пользовательский интерфейс (HTML, CSS)
- **Backend** — серверная логика (FastAPI)
- **Database** — хранение данных (PostgreSQL)
